# projet-fil-rouge
projet de web baccalauréat semestre 1 UQAC 

## Déploiement

Le site est déployé automatiquement sur GitHub Pages à chaque push sur `main`
par le workflow [`.github/workflows/pages.yml`](.github/workflows/pages.yml).
Le dossier publié est [`Code`](Code), dont la page d'entrée redirige vers
[`Fichier_html/connexion.html`](Code/Fichier_html/connexion.html).
